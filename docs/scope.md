# 核赔台范围说明

安澜财险健康险事业部，成都理赔中心。产品只做「安康住院2024」。系统名称是核赔台。

核赔台给专员的是协查建议，决定权在核赔人。它不审批到账，也不代替核赔人签字。

红线：

- 不打款
- 不写核心系统
- 不对外发送
- 资料不足时必须说无法判断

三件贯穿案的期望输出只保留标签和条款号：

- CLM-2026-0901 通过 AK-2024-4.2
- CLM-2026-0777 补充材料 AK-2024-2.1
- CLM-2026-1842 复核 AK-2024-3.1
