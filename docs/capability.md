# 能力边界

队列是 SQLite，没有 Kubernetes，没有独立消息中间件。本机验收仍是 pytest。镜像构建命令：`docker build -f deploy/Dockerfile .`。

## 能做

- 资格判断（规则，零次模型）
- 缺材料时补充材料
- 条款释义（混合检索，带版本日期和条款号）
- 开放协查建议（手写循环，先历史后条款）
- 争议案的证据包（三名工人，冲突则复核）

## 不能做

- 打款
- 写核心系统
- 对外发送（短信必须周衡批准之后才离开系统，未批准不算系统能做的事）
- 资料不足时无法判断，不硬答

已知不做：多租户计费后台、Kubernetes、独立 Redis 或消息队列。下一件后端工作是把 `jobs` 换成真正的消息中间件，而不是再加一层 Prompt。
