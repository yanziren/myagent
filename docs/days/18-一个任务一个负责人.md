**今日产出**

任务卡有编号、唯一负责人和完成标准。状态只在允许的集合里流转。医学工人没有心跳时状态变为超时，组装结果是失败，正文不写「无异常」，负责人仍是医学工人。没确认的交接不改变负责人。`jobs` 增加 `owner` 和 `lease_until`。两个 worker 抢同一行，只有一条条件更新能成功。没有心跳就变成 `timeout`。


标了 **[亲手]** 的自己写。标了 **[AI]** 的，你先把约束写清楚再生成：状态集合、超时文案、交接规则不要让它改。生成之后用 pytest 验收。

**1. [亲手] 写任务卡和状态（30 分钟）**

`claimdesk/multiagent/tasks.py`。

`ALLOWED_STATES = {"assigned", "running", "blocked", "completed", "failed", "timeout", "cancelled"}`

`TaskCard` 字段：`task_id`、`owner`、`done_when`、`output_schema`、`budget`，初始 `state="assigned"`。`transition` 遇到集合外的状态抛 `ValueError`。测试会调用 `transition("guessing")`。

`default_cards()` 三张，负责人各不相同：

| task_id | owner | done_when |
|---|---|---|
| T-MED | medical | 给出异常或无异常 |
| T-CL | clause | 引用条款编号 |
| T-PR | precedent | 给出判例要点 |

每张 `budget` 200。输出结构是一个字段名到类型名的字典，例如 `{"finding": "str"}`。

抢负责人时执行 `UPDATE jobs SET owner=?, lease_until=? WHERE id=? AND lease_until < ?`。测试里两个 worker 抢同一行，成功次数为 1。`owner` 由运行时分配，不由模型填写。租约过期且没有新心跳时，状态变为 `timeout`。

**2. [亲手] 没有心跳就失败闭合（25 分钟）**

`run_medical(card, heartbeat)`：先进入 `running`。`heartbeat` 为假时进入 `timeout` 并返回 `None`。为真时进入 `completed`，返回 `{"finding": "异常", "evidence_id": "E-MED"}`。

`assemble(cards)`：医学卡的状态不是 `completed` 时返回：

- `state == "failed"`
- `owner` 仍是 `"medical"`
- `text` 含「医学」，且不含「无异常」

建议文案使用「无法完成：缺少医学意见」。

`handoff(card, new_owner, confirmed)`：只有 `confirmed` 为真才改 `owner` 并回到 `assigned`。`confirmed` 为假时返回值仍是原来的负责人。

```bash
pytest tests/test_day18_ownership.py -v
```

**解决什么问题**

医学工人没有心跳。如果写作步骤用空结果补上一句材料无异常，周衡会按一份假报告复核。靠提示词让模型自觉分工，超时了仍会交付一份看起来完整的结论。

拒绝的方案：未确认的交接就算换了负责人。超时后仍输出完整的「无异常」。

留下的机制：任务卡有编号、唯一负责人和完成标准。状态只允许已分配、执行中、阻塞、完成、失败、超时、取消。没有心跳就超时。缺医学意见时结论是无法完成，正文不写无异常。没确认的交接不改变负责人。

**技术原理**

主子通信用结构化消息和显式状态，不用自然语言约定。下行消息带任务编号、完成标准和输出结构。上行若没有心跳，编排者按超时处理，而不是再等一个「我快好了」。

责任扩散的根因是没有所有权。五条里今天做三条：单一负责人、交接要确认、异常时不要替缺失的一方编造完成。不属于自己的问题上报编排者，写在 `assemble` 的失败返回里，负责人字段仍指向医学工人，周衡知道找谁。

空结果不是「无异常」。无异常是一项发现，必须来自 `heartbeat` 为真的完成返回。缺失用失败状态表达。

**坑**

**坑 1：超时文案写成「材料无异常，仅供参考」。** 测试要求文本不含「无异常」。用「缺少医学意见」。

**坑 2：未确认交接仍把 owner 改成 writer。** `handoff(..., confirmed=False)` 必须返回 `"medical"`。

**坑 3：非法状态被静默忽略。** `guessing` 要抛 `ValueError`，不要落成一个新字符串。状态机的价值就是拒绝未定义的边。

**卡住时先看这里**

- 三张卡的 `owner` 集合大小必须等于 3。不要两张都叫 medical。
- `run_medical` 在超时前已经把状态写成 `running`，然后再写 `timeout`。组装只看最终状态不是 `completed`。

**验收标准**

- [ ] `pytest tests/test_day18_ownership.py -v` 通过
- [ ] 无心跳时状态是 `timeout`，组装文本不含「无异常」
- [ ] 未确认交接后负责人仍是 medical
- [ ] `transition("guessing")` 抛 `ValueError`
