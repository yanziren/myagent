**今日产出**

新旧模型在黄金集上按场景对比。假条款号变多的切片会挡住发布。评判先交换位置再给结论，和周衡不一致就送人工。影子流量不发送短信。回滚是改配置里的模型日期版本。网关按 `model_version` 做影子调用。专员看到的仍是旧版本结果；影子输出只写 `audit`。


标了 **[亲手]** 的自己写。标了 **[AI]** 的，你先把约束写清楚再生成：切片阈值、影子模式下哪些工具不能真执行、版本号格式不要让它改。生成之后用 pytest 验收。

**1. [亲手] 分场景对比，不看一个总分（30 分钟）**

新建 `claimdesk/release/compare.py`。

`compare(rows) -> dict`。每行有 `scenario`、`old`、`new`。`new` 和 `old` 是建议字典，含 `decision`、`clause_ids`、`fake_clause`。

返回 `by_scenario`。若任一场景里 `fake_clause` 为真的条数比旧版本多，`blocked` 为真，并列出场景名。测试造两个场景：

- `waiting`：10 条里新旧都没有假条款，决策一致
- `cite`：旧版本 0 条假条款，新版本 2 条 `AK-FAKE`

总分可以仍是 90% 一致。`blocked` 必须为真，原因场景含 `cite`。

**2. [亲手] 评判模型的位置交换（25 分钟）**

`pairwise(judge, left, right) -> str` 调用 `judge` 两次，第二次把左右对调。

- 两次都选同一侧（对调后选另一边的那个标签）→ 返回那个标签 `old` 或 `new`
- 两次指向不同物理文本 → 返回 `human`

测试用一个偏爱「左边」的桩：无论内容，永远返回 `left`。交换之后结论必须是 `human`，不能宣布新模型获胜。

再用周衡标过的 4 条小集：桩和周衡的选择一致率达到 4/4 时，`calibrated` 为真；改成 2/4 时为假。门槛写死 `0.85`，4 条里必须全对才过线。这是教学用的小集，用来把校准做成断言，不是统计上的 85% 样本。

网关配置分线上版本和影子版本。`complete` 返回给专员的仍是线上桩的条款号。影子输出只写 `audit.phase=shadow`，不写入建议的 `decision`。

**3. [亲手] 影子与配置回滚（25 分钟）**

`shadow_send(book, ticket_id)` 在影子模式返回 `{"executed": False}`，并且 `book.sent` 不变。测试先批准一张短信，再走影子，`sent` 仍为空。真模式才调用第 11 天的发送。

`ModelConfig` 只有 `model_id`，格式如 `claim-model-2026-10-01`。`rollback(config, previous)` 返回旧 id。测试从 `claim-model-2026-10-18` 切回 `claim-model-2026-10-01`，断言路由读到的是旧 id。不要在代码里写死「最新」。

```bash
pytest tests/test_day27_release.py tests/test_day11_approval.py -v
```

**解决什么问题**

供应商把模型静默升了小版本。1842 的拒答变少了，编造条款号变多。何岚问是变好了还是变坏了。直接切到生产，专员第二天就会按假条款号复核。只看一个总分，`cite` 场景的退步会被 `waiting` 场景的持平盖住。

拒绝的方案：影子流量里把短信再真发一遍。用同一个位置的配对比较宣布新模型更好。

留下的机制：黄金集按场景切片，红线一条都不能破。配对比较交换位置，不一致送人工。影子复制输入，短信和提交不真执行。灰度按专员桶，回滚是改配置。模型使用带日期的固定版本。

**技术原理**

提示词改一个词、模型升一个版本，行为变化是全局的。发布看的是行为对比，不是进程能否启动。离线回归拦住明显退步。影子流量用真实输入分布，但副作用必须走录像或空实现。灰度从 1% 到 5% 再放大，今天的测试把「配置可切回」做成断言，百分数本身留在笔记里。

评判模型偏爱某一侧、偏爱更长的回答、偏爱和自己相似的文风。交换位置能抓住第一种。和周衡的小集不一致，就不要让它单独挡发布。第 2 天的清单式评分仍然是主裁判，评判模型只做配对比较的助手。

**坑**

**坑 1：`blocked` 只在总分下降时才为真。** 测试的总分可以不变。切片上的假条款增加就要挡。

**坑 2：影子模式调用了 `approve` 之后的 `send_sms`。** `book.sent` 会多一条。影子函数在发送前返回。

**坑 3：版本号用 `latest`。** 静默升级正是这个名字掩盖的。配置里是带日期的 id。

**卡住时先看这里**

- 偏爱左边的桩：第一次返回 left，对调后仍返回 left，两次指向的文本不同，结果是 `human`。
- 假条款的判定可以复用第 13 天：条款号不在 `CLAUSE_V3` 的标题里就是 `fake_clause`。

**验收标准**

- [ ] `pytest tests/test_day27_release.py -v` 通过
- [ ] `cite` 场景假条款增加时发布被挡住
- [ ] 偏爱左边的评判结果是 `human`
- [ ] 影子运行不增加 `sent`；配置切回后模型 id 是旧的日期版本
